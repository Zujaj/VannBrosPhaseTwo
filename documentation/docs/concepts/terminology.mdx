# Terminology

Common VannBrosPhaseTwo and farming terms used throughout these docs.

## Core entities

| Term | Meaning |
|---|---|
| **Task / Operation** | A field activity type (e.g. Irrigation, Fertilization, Pruning/Hedging, Weed Control, Harvest, Almond Preparation, Soil Sampling & Testing). The task chosen drives the work-order type. |
| **Machine** | A self-powered unit that does work on its own — tractor, combine harvester, excavator. |
| **Implement** | A tool attached to a machine (usually a tractor) for a specific task — plow (tilling), sprayer (spraying), seeder (planting). |
| **Field / Plot** | The land where crops are grown. Work orders run against selected **plots**, each with a Plot Area and Operational Area (acres). |
| **Crop** | A plant cultivated for food, fiber, animal feed, or commercial use — e.g. almond, pistachio, walnut, rice, cotton, wheat. |
| **Season** | A time period linked to weather/farming activity (Spring, Summer, Autumn/Fall, Winter); also expressed as "Crop Year NNNN". |
| **Tank Mixing** | Combining two or more products (pesticides, herbicides, fungicides, fertilizers) in one spray tank and applying them in a single pass instead of separate sprays. |
| **Observation / Point of Interest (POI)** | A categorized field condition logged on the map — e.g. a pest/insect attack or water logging. Created on mobile. |

## Field tasks (selected)

| Task | What it is |
|---|---|
| **Almond Preparation** | Work related to preparing almond orchards or production. |
| **Insect/Disease Control** | Treatment and control of pests and diseases that damage crops. |
| **Planting/Replant** | Planting new plants or replacing damaged plants. |
| **Sampling** | Collecting soil, water, or crop samples for testing. |
| **Fertilization** | Using fertilizer to provide nutrients to plants. |
| **Irrigation** | Supplying water to crops. |
| **Pollination** | Transfer of pollen in flowers so fruit can develop. |
| **Soil Amending** | Adding compost or organic matter to improve soil quality. |
| **Harvest** | Collecting mature crops or fruits. |
| **Land Preparation** | Leveling and preparing land before cultivation. |
| **Pruning/Hedging** | Cutting extra branches to improve plant growth. |
| **Weed Control** | Removing harmful grass or weeds. |
| **Hulling & Drying** | Removing shells/husks and drying almonds or grains. |
| **Orchard Floor Management** | Keeping orchard soil clean, level, and suitable for cultivation. |

## Chemical safety intervals

| Term | Meaning |
|---|---|
| **Preharvest Interval (PHI)** | Minimum days between the last pesticide application and harvest. |
| **Re-entry Interval (REI)** | Minimum time workers must wait before safely re-entering a treated field. |
| **Rainfast** | Hours after application a pesticide must stay on before rain won't wash it off. |
| **Stockfeed** | Minimum days before treated crops/pasture can be fed to livestock. |
| **Plantback** | Waiting period before planting another crop in treated soil. |
| **Grazing** | Minimum days livestock must be kept off treated pasture. |
| **Infestation** | Large numbers of harmful organisms damaging crops, soil, grain, or livestock. |
| **Water logging** | Excess water in the soil reducing root oxygen and harming crop growth. |

## Rate units

Units available when entering material application rates.

| Unit | Full name | Metric equivalent | Common use |
|---|---|---|---|
| 1/2 pt | Half Pint | 236.6 mL | Small liquid measurements |
| cl | Centiliter | 10 mL | Beverage & chemical measurements |
| dl | Deciliter | 100 mL | Lab & agricultural formulations |
| fl. oz | Fluid Ounce (US) | 29.57 mL | Liquid fertilizers, pesticides, additives |
| gal | Gallon (US) | 3.785 L | Large-volume agricultural applications |
| l | Liter | 1,000 mL | Standard metric liquid measurement |
| ml | Milliliter | 0.001 L | Precise dosing & mixing |
| pt | Pint (US) | 473.2 mL | Medium liquid quantities |

:::tip Mix Method
In material templates and tank-mix work orders, **Per Area** means the rate is per acre; **Per Volume** means per gallon or per 100 gallons. See [Create a Material Template](../user-journeys/templates/create-material-template).
:::
