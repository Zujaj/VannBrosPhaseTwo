# Observations: Configure POI Categories

**Who:** Manager / Administrator (a [role](../../concepts/roles) with settings access)  **Where:** Web

A **Point of Interest (POI) Category** defines a type of field condition that can be logged as an observation — for example *Spider Mite Attack* or *water logging* — with its own title, color, and icon. You configure these categories on the **web** so that they are available when observations are created and so they can be toggled as layers on the Maps screen.

:::note Observations are created on mobile
Observations / POIs are **created on mobile** (manager-only on mobile per the intro deck). The **web** is used to (a) configure POI categories on this page and (b) [convert an existing observation into a work order](./create-work-order-from-observation).
:::

## Before you start

:::note Prerequisites
- A user account with permission to open **Settings** and edit **Map Toggle Config**.
- An idea of the title, color, and icon you want the new category to use.
:::

## Steps

1. Click the **Settings** gear, then open **Map Toggle Config** from the left bar. The page shows collapsible sections: **Stages**, **Crops**, **Task**, **Work Orders**, and **Observation Categories**.
2. Click **Create New POI Category** (top-right). The **Create Point of Interest Category** panel opens.
3. Fill in the required fields:
   - **Enter Title\*** — e.g. *Spider Mite Attack*
   - **Select Color\*** — pick a swatch (red / amber / green / blue)
   - **Select Icon\*** — choose an icon (info, shield/exclamation, list/bars, water-drop, leaf)
4. Turn the **Active** toggle on. (The **Visible** toggle controls map visibility and is on by default.)
5. Click **Save**.

## Result

The new category appears under **Observation Categories** on the **Map Toggle Config** page. It becomes available for tagging observations and shows up as a togglable layer on the Maps screen alongside other observation layers.

## Notes & gotchas

:::warning Required fields
**Enter Title\***, **Select Color\***, and **Select Icon\*** are all required — you cannot **Save** until each is set.
:::

- The **Active** toggle controls whether the category is usable; the **Visible** toggle controls whether its observations appear on the map (on by default).
- Example categories you may already see: *water logging*, *Spider Mite Attack*, *POI Cat*.
- Once categories exist, observations logged on mobile can be turned into work orders on web — see [Create a Work Order from an Observation](./create-work-order-from-observation).
