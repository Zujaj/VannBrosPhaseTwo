# Communication Center: Chat & Communications

**Who:** Any user with menu access (no role restriction stated)  **Where:** Web

The **Communication Center** is the Farm App's in-app messaging hub. It supports one-to-one and group conversations with text, photos, documents, and voice notes. Contacts appear as `Name | NNNNNN` (employee/user ID), e.g. *Jose Velasquez | 000015*.

## Before you start

:::note Prerequisites
- A user account with access to the **Communication Center** menu (older builds label it **Messaging**).
- The people you want to message exist as users in VannBrosPhaseTwo.
:::

## Steps

### Start a 1:1 chat

1. Open the **Communication Center** from the top nav.
2. Click the **+** icon (top-left, next to **Messages**), then choose **New Chat**.
3. In the **Chat Now** dialog, use **Search User** to find and select the person.
4. Type your message, then **send**.

### Start a group chat

1. Open the **Communication Center** and click the **+** icon.
2. Choose **Group Chat**.
3. In the **Create group chat** dialog, enter the group's name, then click **Create**.
4. In the **Create New Group** panel, search for and select participants (use **x** to remove anyone added by mistake).
5. Click **Next** (the green next icon).
6. Type your message, then **send**. The group header shows the name plus **View details**.

### Send an attachment

1. In the chat composer, click the **camera** icon (photos) or the **paperclip** icon (documents).
2. Pick the file and click **Open**.
3. Click **Send**.

### Record a voice note

1. In the chat composer, click the **microphone** icon.
2. Speak — a timer shows (e.g. *00:06*).
3. Click **done** (the blue check) to send, or **x** to cancel.

## Result

Your message, attachment, or voice note appears in the conversation thread with a timestamp. Media messages are labeled by type (e.g. `AUDIO`) in the Messages list.

## Notes & gotchas

- Use the **Search** box to filter the Messages list, and the **Type a message** field to compose.
- Composer controls are: **camera**, **microphone**, **paperclip**, and **Send**.
- Dialogs you will see: **Chat Now** (*Search User*); **Create group chat** (*Enter group's name*, Cancel / Create); **Create New Group** (participant multi-select).
- Empty state: *Welcome, &lt;user&gt;*, *Here Are Some Quick Actions To Get You Started*, *Search for someone to start chatting with*, plus a **New Conversation** button.
- No required fields, statuses, or error messages are documented for chat.
