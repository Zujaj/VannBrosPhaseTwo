# Work Orders: Create a Tank Mix Work Order

**Who:** Supervisor / Manager (a [role](../../concepts/roles) with work-order authoring rights)  **Where:** Web (authored & submitted on web; executed on mobile)

A **Tank Mix Work Order** is a work order whose task is a **tank-mix operation**. It works like a [Planned WO](./create-planned-work-order) but its materials carry `Unit`, `Mix Method`, and `Per` values plus **Liquid Application** parameters, and it can optionally pull materials from a [Material Template](../templates/create-material-template). You author and submit it on web; field crews execute it on mobile; a [Manager approves it](./approve-work-order) to reach `Done`.

```mermaid
flowchart LR
  H["Header + tank-mix Operation"] --> B["+ Add Block (plots)"] --> M["Materials: Template (A) or manual (B)<br/>set Unit / Mix Method / Per"] --> TM["Edit Tank Mixing Details<br/>(Liquid Application)"] --> R["Resources + Assets"] --> S["Supervisor (last)"] --> Sub["Submit → Save"]
```

## Before you start

:::note Prerequisites
- A user account with permission to create work orders.
- The **Task/Operation** you pick must be a **tank-mix operation** (e.g. *Pest Preventive Mix Spray (2014)*).
- If you want materials to auto-fill, create the [Material Template](../templates/create-material-template) first.
:::

The Work Orders list lives at `https://vannbrosphasetwo-<client>-<env>.folio3.site/workorders`.

## Steps

1. Log in to VannBrosPhaseTwo web and go to the **Work Orders** tab.
2. Click **Create New Work Orders** (top-right).
3. Fill in the header fields:
   - **Work Order Name\***
   - **WO Start Date\*** and **WO End Date\***
   - **Priority\*** — `Low`, `Medium` (default), `High`, or `Urgent`
   - **Farm\***
   - **Operation\*** — must be a **tank-mix operation** (labelled `Operation` / `Task` depending on render)
   - **Supervisor\*** — the resource who manages the WO. **Select this last** (see gotchas); skip it for now.
   - **Responsible** — optional
   - **Material Template** — optional; tank-mix only (see path A below)
   - **Notes** — optional
4. Add plots under **Select Plot\***: click **`+ Add Block`** → **Select Blocks / Plots** modal → check plots → **Save**. (Use `+ Add Block`, not the adjacent `Select Range` date filter; `Add Block Using Map` is the map-based alternative.)

Now add materials using **one** of the two paths below.

### Path A — Via a Material Template

1. Pick a template from the **Material Template** dropdown. The materials auto-fetch into **Select Materials** and tank-mix info appears in the right panel.
2. For each material, edit `Rate`, `Unit`, `Mix Method`, and `Per`.
3. Click the **Tank Mixing** link → **Additional Information → Edit Tank Mixing Details** → set the [Liquid Application parameters](#edit-tank-mixing-details-liquid-application) → **Save**.

### Path B — Manually (without a template)

1. Click **+** on **Select Materials** to open the modal, check the materials, then click **Save**.
2. In the materials grid set `Rate`, `Unit`, `Mix Method`, and `Per`.
3. Click the **Tank Mixing** link → **Additional Information → Edit Tank Mixing Details** → set the [Liquid Application parameters](#edit-tank-mixing-details-liquid-application) → **Save**.

The tank-mix materials grid columns are: `Material`, `Rate`, `Unit` (e.g. `fl. oz`, `1/2 cu. in`), `Mix Method`, `Per` (Per Area / acre or Per Volume / 100 gal), `Action`.

### Edit Tank Mixing Details (Liquid Application)

In **Edit Tank Mixing Details**, set the Liquid Application parameters:

- `Application Method` (e.g. *Air-blast Sprayer*, *Air-Aid Sprayer*)
- `Total Application Rate (gal/ha)`
- `Tank Size (gal)`
- `Nozzle Type` (e.g. *Air Induced*)
- `Droplet Size` (e.g. *Very Fine*)
- `Preharvest (PHI) (days)`

The right panel **Additional Details** shows the `Application Type` (e.g. *Liquid*).

### Finish

1. Assign **Resources** and **Assets** as in the [Planned WO flow](./create-planned-work-order) (resources via the **Resource Group** dropdown; assets via the **Select Assets** modal).
2. Now select the **Supervisor\*** (skipped in step 3), click **Submit**, then click **Save** in the **Create Work Order** confirm dialog (`Are You Sure You Want To Save The Work Order`).

:::warning Submit is not Save — and pick Supervisor last
**Submit** only opens the confirm dialog; its **`Save`** persists the WO. A section save also re-renders the form and **wipes an early Supervisor pick**, leaving Submit disabled — choose the Supervisor **last**.
:::

:::tip
Use **Save As** in the form header to save a `Draft` instead of submitting.
:::

## Result

You'll see a success toast (title **`Success`**) like **`Work Order WO-640 | Almond Prep 06/08/2026-1 Saved Successfully`**. After you confirm with **Save**, the WO enters the **Queue / To Do** state and becomes visible on mobile. After mobile execution it reaches `Review`; a Manager then runs **Work Order Completed → Approve** to move it to `Done`. See [Approve a Work Order](./approve-work-order) and the [create flow diagram](../../diagrams/work-order-create-flow).

## Notes & gotchas

:::warning Task type gates the flow
A tank-mix WO requires a tank-mix task. If you choose a non-tank-mix task, the **Tank Mixing** sections and `Mix Method` / `Per` material fields won't appear — pick a tank-mix operation or use the [Planned WO](./create-planned-work-order) flow.
:::

- The **Material Template** dropdown is the only difference between path A and path B; both end at **Edit Tank Mixing Details**.
- Unlike a Planned WO (where `Rate` is simply per acre), tank-mix materials add `Mix Method` and `Per` (Per Area vs Per Volume).
- Only **one Responsible Person** can be set per WO at a time.
- A work order created on web is visible on the mobile screen.
- Building the materials for a tank mix uses the [Create Material Template](../templates/create-material-template) flow.
- See the [Work Order Lifecycle](../../concepts/work-order-lifecycle) for the full status flow.
