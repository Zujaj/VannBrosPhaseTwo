## Failures

- **FINDINGS #62:** `POST /api/harvestcentral/tickets/plan` accepts pairs that are neither contracted nor growing (HMF-15, HMF-18). The web UI never offers these pairs, so a user cannot create them from the app; any other API client can. Not filed in ADO yet.
- **FINDINGS #60 (expected fail):** `GetFieldsForHarvesting` returns 69 plots: the 51 Vann plots and 18 plots that appear only on other GP growers' contracts. `Almonds Splits & Meats` is on no contract and has no varieties. This finding stays in FINDINGS and is not filed in ADO, by the user's decision.
